3 · Connect an AI agent (MCP)

Local agents (Claude Code / Desktop) need no tunnel. For claude.ai web, start the HTTP server and a public tunnel, then paste the connector URL.

Everything runs locally — the tunnel is just ngrok on this machine, no cloud setup. It does make this machine reachable publicly, so keep read-only on, treat the URL as a secret, and stop the tunnel when you're done.

The MCP server runs inside this panel on its own port, so it shares the vault index safely. Because embedded Qdrant allows only one client, don't run a second command (like knowledge watch or knowledge mcp) in a terminal while the panel is open — use the buttons here instead.
